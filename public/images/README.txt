PUT YOUR IMAGES HERE
--------------------
Files in this folder are served from "/images/...".

Example:
  1. Copy  profile.jpg  into this folder.
  2. In src/data/portfolioData.js set:   image: "/images/profile.jpg"

Suggested sizes
  Profile photo   : 800 x 1000 px (4:5 portrait)
  Project images  : 1200 x 750 px (16:10 landscape)
